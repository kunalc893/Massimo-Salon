# Massimo Salon & Academy — concept demo

A responsive browser demo made with plain HTML, CSS and vanilla JavaScript. No Node.js, framework or build process is needed. It is designed to be easy to open, review and edit in VS Code, and to support a sales presentation before the client commissions the production WordPress website.

## Preview locally

1. Extract the ZIP file.
2. In VS Code, choose **File → Open Folder** and open `massimo-demo`.
3. Open `index.html` in a browser. For convenient local preview and auto-refresh, install Microsoft's **Live Server** extension, right-click `index.html`, then choose **Open with Live Server**.
4. The external Google Fonts and Unsplash concept photos need an internet connection. Replace the remote photos with client-approved salon photos before production.

## Files

- `index.html` — page content and sections.
- `styles.css` — colors, type, layout and responsive behavior.
- `script.js` — mobile navigation, current year and WhatsApp enquiry form.

The form opens WhatsApp at the supplied number with the enquiry details. It does not save form data or automatically confirm an appointment. The demo intentionally does not invent the salon's address, business hours, ratings or customer testimonials. Gallery and hero photography is illustrative concept imagery and should be replaced with images approved for Massimo before publishing.

## Hostinger and WordPress

This folder is a presentation prototype, not the production WordPress theme. When the client approves a direction, build the commissioned WordPress site/theme for Hostinger and add the client's confirmed content, photos, address and hours. This standalone folder can also be hosted as a static preview, but it will not provide WordPress Admin editing.
